Edu Streak 🎯
A Duolingo-style coding learning platform built with PHP, MySQL and Tailwind CSS.
Setup

Clone the repo
Copy app/config/app.example.php to app/config/app.php and fill in your credentials
Import the database schema
Run composer install
Run npm install && npm run dev
Start server with php -S localhost:3000 -t public

Tech Stack

PHP (MVC)
MySQL
Tailwind CSS v4
Google OAuth

Features

🌐 Multi-language support (C++, C#, CSS, HTML, Java, JavaScript, PHP, Python)
📈 Lesson progress tracking
🏆 Monthly leaderboard
🔥 Streak system
💰 Gem & heart system with shop
🎯 Daily & extra quests
👤 Google OAuth profile
📜 Code history page
