# Edu Streak 🎯

A Duolingo-style coding learning platform built with PHP, MySQL and Tailwind CSS.

## Setup
1. Clone the repo
2. Copy `app/config/app.example.php` to `app/config/app.php` and fill in your credentials
3. Import the database schema
4. Run `composer install`
5. Run `npm install && npm run dev`
6. Start server with `php -S localhost:3000 -t public`

## Tech Stack
- PHP (MVC)
- MySQL
- Tailwind CSS v4
- Google OAuth
